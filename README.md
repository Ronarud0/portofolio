# Portfolio Website - Ronald Putra

Portfolio website yang mewah, profesional, dan modern untuk menampilkan skills, experience, dan projects sebagai Web Developer & UI/UX Designer.

## 🚀 Features

- **Fully Responsive Design** - Terlihat sempurna di semua device (desktop, tablet, mobile)
- **Modern UI/UX** - Desain yang elegan dan profesional dengan gradient dan animasi smooth
- **Smooth Animations** - Menggunakan AOS (Animate On Scroll) library
- **Typing Animation** - Hero section dengan efek typing yang dinamis
- **Dark/Light Elements** - Kombinasi warna yang menarik dan modern
- **Interactive Elements** - Hover effects, ripple effects, dan smooth scrolling
- **Bootstrap 5** - Menggunakan framework Bootstrap terbaru untuk responsive grid
- **Font Awesome Icons** - Icon library yang lengkap
- **Google Fonts (Poppins)** - Typography yang modern dan readable

## 📋 Sections

1. **Home/Hero** - Introduksi dengan typing animation dan CTA buttons
2. **About** - Deskripsi profesional dengan foto dan informasi personal
3. **Skills** - Technical skills dengan progress bar dan soft skills cards
4. **Projects** - Showcase project dengan gambar dan teknologi yang digunakan
5. **Experience** - Timeline professional experience
6. **Education** - Academic background
7. **Contact** - Social media links dan contact information

## 🎨 Customization

### 1. **Ganti Foto Profil**
- Ganti placeholder di section About dengan foto Anda
- Update path: `https://via.placeholder.com/400x400?text=Your+Photo` dengan foto Anda
- Recomended size: 400x400px

### 2. **Update Social Media Links**
```html
<!-- Update dengan username Instagram Anda yang benar -->
<a href="https://instagram.com/your_username" class="social-link">
    <i class="fab fa-instagram"></i>
</a>

<!-- Update dengan LinkedIn profile URL -->
<a href="https://linkedin.com/in/your_profile" class="social-link">
    <i class="fab fa-linkedin-in"></i>
</a>

<!-- Update dengan GitHub profile URL -->
<a href="https://github.com/your_username" class="social-link">
    <i class="fab fa-github"></i>
</a>
```

### 3. **Update Project Image**
- Ganti placeholder project image dengan screenshot project Anda
- Update di section Projects: `<img src="path/to/your/project-screenshot.png">`

### 4. **Download CV Button**
- Update button "Download CV" di About section
- Set link ke file CV PDF Anda

## 🌐 Cara Menggunakan

### Via XAMPP (Local)
1. Letakkan folder `portofolio` di `C:\xampp\htdocs\`
2. Start Apache di XAMPP Control Panel
3. Buka browser dan akses: `http://localhost/portofolio/`

### Via Live Server (VS Code Extension)
1. Install extension "Live Server" di VS Code
2. Klik kanan pada `index.html`
3. Pilih "Open with Live Server"

### Deploy ke GitHub Pages
1. Buat repository GitHub
2. Push semua file ke repository
3. Go to Settings > Pages
4. Select branch main dan folder /root
5. Website akan tersedia di `https://username.github.io/repository-name`
