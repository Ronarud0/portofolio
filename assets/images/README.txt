INSTRUKSI FOTO PROFIL
===================

1. Simpan foto profil Anda di folder ini
   - Nama file: photo.jpg atau photo.png (atau nama apapun)
   - Ukuran optimal: 400x400 pixel
   - Format: JPG atau PNG

2. Contoh nama file yang bisa digunakan:
   - profile.jpg
   - foto-profil.jpg
   - my-photo.png
   - ronald-putra.jpg

3. Setelah menyimpan foto, update index.html:
   - Buka file index.html
   - Cari: https://via.placeholder.com/400x400?text=Your+Photo
   - Ganti dengan: assets/images/nama-file-anda.jpg

Contoh:
<img src="assets/images/profile.jpg" alt="Ronald Putra" class="img-fluid rounded-circle">

Catatan: Foto akan tampil dalam bentuk lingkaran (rounded-circle)
